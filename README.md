# logmint LP

シンプルな静的ランディングページです。Noto Sans、指定カラーパレット（#23A0C3 / #5FC3A7）を使用しています。

## 使い方

1. `index.html` をブラウザで開く
   - もしくはローカルサーバーで配信：

```bash
python3 -m http.server 5173
```

2. ページ下部とヒーローの「アンケートに回答する」のリンクを、実際のアンケートURLに変更してください。

## 構成

- `index.html` 本文、セマンティックHTML、OGメタ
- `styles.css` レスポンシブCSS、配色、アクセシビリティ（フォーカス、コントラスト）
- `README.md` このファイル

## カスタマイズ

- 配色は `styles.css` 冒頭のCSSカスタムプロパティで調整可能です。
- セクションの並びやコピーは `index.html` 内の該当箇所を編集してください。
